# Wutete
ውጤቴ

Academic toolkit for Ethiopian university students.

## 🚀 Live Demo

**https://wutete.vercel.app**

Try Wutete live — GPA calculator, CGPA calculator, and GPA target planner for Ethiopian university students.

## Features

- GPA Calculator
- CGPA Calculator
- GPA Target Planner
- What-If Grade Planning

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- ESLint

## Deployment

Deployed on Cloudflare Pages (free tier).
